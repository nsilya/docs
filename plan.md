### 3. Принцип Парето: 20% Ключевых Узлов (80% ценности)
*Сфокусируйся здесь. Это твой минимум для собеседования и первой задачи.*

1.  **SQL (Advanced):** Ты должен писать сложные запросы с закрытыми глазами. Это 50% успеха на собеседовании.
2.  **Python (Scripting):** Умение написать скрипт, который заберет данные, почистит и положит куда-то. Не Data Science, именно скриптинг.
3.  **Airflow:** Понимание, как оркестрировать задачи. Это маркер «инженера», а не просто аналитика.
4.  **Git + Linux:** Базовая гигиена труда. Без этого код не существует.
5.  **AWS S3:** Понимание облачного хранения (объекты, бакеты, права).

**Стратегия:** Делай проект, используя только этот набор. Например: *Скрипт на Python забирает данные API -> Кладет в S3 -> Airflow триггерит SQL-загрузку в Базу.*
